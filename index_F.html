🛡️ Cloudflare 프록시 (CORS 완전 해결)

DeepL은 브라우저 직접 호출 시 CORS로 막힙니다. Cloudflare Workers 프록시 URL을 등록하면 CORS 없이 안전하게 호출됩니다. (아래 📖배포 → Cloudflare 코드 참고)

프록시 경유로 호출 (권장)
프록시를 켜면 DeepL·Google 요청이 모두 프록시를 거쳐 나갑니다. API 키는 프록시가 아니라 이 앱 → 프록시 요청 헤더로 전달되며 프록시는 그대로 API에 중계만 합니다. (키를 Worker에 심어두는 안전한 방식도 배포 가이드에 포함)
🔒 API 키·프록시 URL은 이 기기의 브라우저(localStorage)에만 저장됩니다. 공용 PC에서는 사용 후 삭제하세요.

📖 배포 & 중복 반복 문제 해결

🔧 "같은 말이 여러 번 반복 통역되던" 원인과 수정

원인 1 — 재시작 시 이전 세션 결과 재방출
음성인식이 끊긴 뒤 자동 재시작(onend→start)할 때, 안드로이드 Chrome이 직전 문장을 새 세션에서 또 final로 방출하여 같은 문장이 2∼3번 통역됐습니다.

원인 2 — 중복 방지 로직 부재
이전 버전은 들어온 텍스트를 무조건 통역했습니다. "방금 처리한 문장인지" 확인이 없었습니다.

✅ 이 버전의 3중 방어막
① lastFinal 비교 — 직전 처리 문장과 동일하면 무시
② 시간 필터(3초) — 3초 내 동일 텍스트 반복 차단
③ 세션 격리 — 재시작 때 인식 상태·처리 락 초기화
④ 처리 락 — 통역 진행 중 같은 문장 재진입 방지

🛡️ Cloudflare Workers 무료 프록시 (DeepL/Google CORS 완전 해결)

DeepL API는 CORS 헤더를 주지 않아 브라우저에서 직접 호출하면 실패합니다. 아래 Worker 하나로 DeepL·Google 모두 프록시하여 CORS를 완전히 없앱니다. 무료 플랜 하루 10만 요청이면 통역엔 충분합니다.

① Cloudflare Worker 배포 (5분)
1
dash.cloudflare.com 가입 → 좌측 Workers & Pages → Create → Create Worker
2
이름 지정(예: translate-proxy) → Deploy → Edit code
3
기본 코드를 모두 지우고 아래 코드를 붙여넣기 → Deploy
4
생성된 https://translate-proxy.내계정.workers.dev 주소를 복사 → 설정의 프록시 URL에 붙여넣고 토글 ON

📄 Worker 코드 (그대로 복사)

// ===== Cloudflare Workers · DeepL/Google 번역 프록시 =====
// CORS 완전 해결용. 하루 10만 요청 무료.
// (선택) 키를 여기 심어두면 앱에 키를 넣지 않아도 됩니다.
const DEEPL_KEY  = "";   // 예: "xxxxxxxx:fx"  (비우면 앱이 보낸 키 사용)
const GOOGLE_KEY = "";   // 예: "AIzaSy..."    (비우면 앱이 보낸 키 사용)

export default {
  async fetch(request) {
    const cors = {
      "Access-Control-Allow-Origin": "*",
      "Access-Control-Allow-Methods": "GET,POST,OPTIONS",
      "Access-Control-Allow-Headers": "Content-Type,Authorization,X-Api-Key",
      "Access-Control-Max-Age": "86400",
    };
    if (request.method === "OPTIONS")
      return new Response(null, { headers: cors });

    const url = new URL(request.url);

    // 헬스체크: GET / → ok
    if (request.method === "GET" && url.pathname === "/")
      return json({ ok: true, service: "translate-proxy" }, cors);

    try {
      const body = await request.json();
      const engine = body.engine;          // "deepl" | "google"
      const text   = body.text || "";
      const source = (body.source || "").toLowerCase();
      const target = (body.target || "").toLowerCase();
      const context = body.context || "";
      const clientKey = request.headers.get("X-Api-Key") || body.key || "";

      if (engine === "deepl") {
        const key = DEEPL_KEY || clientKey;
        if (!key) return json({ error: "no deepl key" }, cors, 400);
        const isFree = /:fx$/.test(key.trim());
        const host = isFree ? "https://api-free.deepl.com"
                            : "https://api.deepl.com";
        const p = new URLSearchParams();
        p.append("text", text);
        p.append("source_lang", deeplLang(source, false));
        p.append("target_lang", deeplLang(target, true));
        if (context) p.append("context", context);
        const r = await fetch(host + "/v2/translate", {
          method: "POST",
          headers: {
            "Authorization": "DeepL-Auth-Key " + key.trim(),
            "Content-Type": "application/x-www-form-urlencoded",
          },
          body: p.toString(),
        });
        const j = await r.json();
        const out = j?.translations?.[0]?.text || "";
        if (!out) return json({ error: "deepl empty", raw: j }, cors, 502);
        return json({ text: out }, cors);
      }

      if (engine === "google") {
        const key = GOOGLE_KEY || clientKey;
        if (!key) return json({ error: "no google key" }, cors, 400);
        const r = await fetch(
          "https://translation.googleapis.com/language/translate/v2?key="
            + encodeURIComponent(key.trim()),
          {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: JSON.stringify({ q: text, source, target, format: "text" }),
          }
        );
        const j = await r.json();
        const raw = j?.data?.translations?.[0]?.translatedText || "";
        if (!raw) return json({ error: "google empty", raw: j }, cors, 502);
        const out = decodeEntities(raw);
        return json({ text: out }, cors);
      }

      return json({ error: "unknown engine" }, cors, 400);
    } catch (e) {
      return json({ error: String(e) }, cors, 500);
    }
  },
};

function deeplLang(c, isTarget) {
  const m = { ko: "KO", en: isTarget ? "EN-GB" : "EN", cs: "CS" };
  return m[c] || c.toUpperCase();
}
function decodeEntities(s) {
  return s.replace(/&/g, "&").replace(/</g, "<")
          .replace(/>/g, ">").replace(/"/g, '"')
          .replace(/'/g, "'").replace(/&#(\d+);/g,
            (_, d) => String.fromCharCode(+d));
}
function json(obj, cors, status = 200) {
  return new Response(JSON.stringify(obj), {
    status,
    headers: { ...cors, "Content-Type": "application/json" },
  });
}
✅ 이 앱은 프록시로 POST { engine, text, source, target, context, key } 형식으로 요청합니다. 위 코드는 이 형식을 그대로 처리하도록 작성되어 있으니 수정 없이 바로 동작합니다.
더 안전한 방식: Worker 코드 상단 DEEPL_KEY/GOOGLE_KEY에 키를 직접 넣으면, 앱에는 키를 저장하지 않고 프록시 URL만 넣어도 됩니다. (설정에서 엔진 선택 + 프록시 ON + 키 입력란은 비워둠)
